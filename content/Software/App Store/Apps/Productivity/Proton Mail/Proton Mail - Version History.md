> [!info] Version 7.0.5
> [[2025-10-03|10/03/2025]]
> **7.0.5**
> We've completely rebuilt the Proton Mail app to give you a faster, smoother, and more reliable experience. Faster performance: Emails open instantly, scrolling is fluid, and routine actions like archiving or replying are now faster too! Modern design: A refreshed interface with simpler navigation makes it easier to manage your inbox. Offline mode: Read, write, and organize emails even without internet. Everything syncs when you're back online.
>
> Features:
> - Expire message: You can now set the expiration time for new messages.
> - Signature Settings: Account signature and mobile footer now have their own section in the settings.
>
> Fixes:
> - Multiple fixes to improve performance and reduce network load, improving sync speed.
> - Fixed an issue causing sending emails to fail
> - Deleted messages would reappear as unread
> - The message remains in the Inbox when you select it and try to move it to a folder
> - Fixed issue that would cause Unsubscribe calls to fail infinitely in the queue
> - Improved Dark mode lock screen so it doesn't look like a light mode icon
> - Fixed a bug where remote images wouldn't always block tracking information
> - Remove notifications for messages that are read
> - Move to menu is now closed after using it via the swipe actions
> - The quick actions on a push notification do not work or are delayed
