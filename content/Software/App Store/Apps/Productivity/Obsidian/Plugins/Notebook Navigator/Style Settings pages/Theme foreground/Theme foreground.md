# Theme foreground
Base foreground variables used by Notebook Navigator.
## Foreground colors
### Base foreground
Base foreground color.

> [!info] In `plugins/obsidian-style-settings/data.json`
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> This setting affects the default text color, icons, and backgrounds of Notebook Navigator.
> 
> Only values set through the color picker are accepted; manually editing the JSON file will have no effect.
> 
> **Default:**
> ```JSON
>   "notebook-navigator-style-settings@@nn-theme-foreground@@light": "#",
>   "notebook-navigator-style-settings@@nn-theme-foreground@@dark": "#"
> ```
> If `⟲` is clicked, the JSON property will be removed from `data.json`.
### Muted foreground
Muted foreground color.

> [!info] In `plugins/obsidian-style-settings/data.json`
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> This setting affects the default icon colors and file count colors of Notebook Navigator, as well as the weekday, week, and arrows on Notebook Navigator's calendar.
> 
> Only values set through the color picker are accepted; manually editing the JSON file will have no effect.
> 
> **Default:**
> ```JSON
>   "notebook-navigator-style-settings@@nn-theme-foreground-muted@@light": "#",
>   "notebook-navigator-style-settings@@nn-theme-foreground-muted@@dark": "#"
> ```
> If `⟲` is clicked, the JSON property will be removed from `data.json`.
### Faded foreground
Faded foreground color.

> [!info] In `plugins/obsidian-style-settings/data.json`
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> This setting affects the faded text color of Notebook Navigator, such as for the calendar dates and word count.
> 
> Only values set through the color picker are accepted; manually editing the JSON file will have no effect.
> 
> **Default:**
> ```JSON
>   "notebook-navigator-style-settings@@nn-theme-foreground-faded@@light": "#",
>   "notebook-navigator-style-settings@@nn-theme-foreground-faded@@dark": "#"
> ```
> If `⟲` is clicked, the JSON property will be removed from `data.json`.
### Faint foreground
Faint foreground color.

> [!info] In `plugins/obsidian-style-settings/data.json`
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> This setting affects the color of Notebook Navigator's indent guides.
> 
> Only values set through the color picker are accepted; manually editing the JSON file will have no effect.
> 
> **Default:**
> ```JSON
>   "notebook-navigator-style-settings@@nn-theme-foreground-faint@@light": "#",
>   "notebook-navigator-style-settings@@nn-theme-foreground-faint@@dark": "#"
> ```
> If `⟲` is clicked, the JSON property will be removed from `data.json`.
