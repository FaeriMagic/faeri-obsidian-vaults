## Other
#### Image link format
Select the format in which the image links will be added to cover / banner / icon properties
- link (*"link"*)
- embed (*"embed"*)
- raw path (*"raw"*)
> [!info] In [[Pretty Properties - data.json|data.json]]
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> **Default:**
> ```JSON
>   "imageLinkFormat": "link"
> ```
