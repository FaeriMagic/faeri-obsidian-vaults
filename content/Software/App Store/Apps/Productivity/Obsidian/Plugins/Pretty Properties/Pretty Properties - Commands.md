## Pretty Properties: Remove banner
Removes the banner image from the current note by clearing the banner property from its frontmatter. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Remove cover 
Removes the cover image from the current note by clearing the cover property from its frontmatter. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Remove icon
Removes the icon from the current note by clearing the icon property from its frontmatter. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Select banner image
Opens a prompt to choose a banner image for the current note, writing the selection to the banner property in frontmatter. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Select cover image
Opens a prompt to choose a cover image for the current note, writing the selection to the cover property in frontmatter. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Select cover shape
Opens a prompt to choose the display shape for the current note's cover image, such as vertical, horizontal, square, or circle. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Select icon
Opens a prompt to choose an icon for the current note, writing the selection to the icon property in frontmatter. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Show images menu
Opens a menu with options for managing the current note's banner, cover, and icon images in one place. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Toggle reveal / hide hidden properties
Shows or hides properties that have been configured as hidden in Pretty Properties settings, letting you temporarily view them without changing your settings. Requires the [[Pretty Properties]] community plugin by Anareaty.
## Pretty Properties: Update task count
Manually triggers a recalculation of task counts for the current note, updating the relevant frontmatter properties with the latest values. Requires the [[Pretty Properties]] community plugin by Anareaty.
