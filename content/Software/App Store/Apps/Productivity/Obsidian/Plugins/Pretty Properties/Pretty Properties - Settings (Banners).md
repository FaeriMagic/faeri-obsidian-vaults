## Banners
#### Enable banners
> [!info] In [[Pretty Properties - data.json|data.json]]
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> **Default:**
> ```JSON
>   "enableBanner": true
> ```
#### Banner property
**Requires `"enableBanner": true`.**
> [!info] In [[Pretty Properties - data.json|data.json]]
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> **Default:**
> ```JSON
>   "bannerProperty": "banner"
> ```
