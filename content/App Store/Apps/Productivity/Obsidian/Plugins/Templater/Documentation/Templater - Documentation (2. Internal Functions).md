# Internal Functions

The different internal variables and functions offered by [[Templater]] are available under different **modules**, to sort them. The existing **internal modules** are:

- [[Templater - Documentation (2.1. tp.app)|App module]]: `tp.app`
- [[Templater - Documentation (2.2. tp.config)|Config module]]: `tp.config`
- [[Templater - Documentation (2.3. tp.date)|Date module]]: `tp.dat
- [[Templater - Documentation (2.4. tp.file)|File module]]: `tp.file`
- [[Templater - Documentation (2.5. tp.frontmatter)|Frontmatter module]]: `tp.frontmatter`
- [[Templater - Documentation (2.6. tp.hooks)|Hooks module]]: `tp.hooks`
- [[Templater - Documentation (2.7. tp.obsidian)|Obsidian module]]: `tp.obsidian`
- [[Templater - Documentation (2.8. tp.system)|System module]]: `tp.system`
- [[Templater - Documentation (2.9. tp.web)|Web module]]: `tp.web`

If you understood the [[Templater - Documentation (1.3. Syntax)#Objects hierarchy|object hierarchy]] correctly, this means that a typical internal function call looks like this: `<% tp.<module_name>.<internal_function_name> %>`

## Contribution

I invite everyone to contribute to this plugin development by adding new internal functions. More information [[Templater - Documentation (2.10. Contributing)|here]].
