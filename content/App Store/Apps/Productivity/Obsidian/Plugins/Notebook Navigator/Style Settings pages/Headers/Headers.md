# Headers
Customize pane header appearance.
## Header action buttons
### Button icon color
Default icon color for header buttons

> [!info] In `plugins/obsidian-style-settings/data.json`
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> This setting affects the buttons at the top of the Notebook Navigator panes.
> 
> Only values set through the color picker are accepted; manually editing the JSON file will have no effect.
> 
> **Default:**
> ```JSON
>   "notebook-navigator-style-settings@@nn-theme-header-button-icon-color@@light": "#",
>   "notebook-navigator-style-settings@@nn-theme-header-button-icon-color@@dark": "#"
> ```
> If `⟲` is clicked, the JSON property will be removed from `data.json`.
