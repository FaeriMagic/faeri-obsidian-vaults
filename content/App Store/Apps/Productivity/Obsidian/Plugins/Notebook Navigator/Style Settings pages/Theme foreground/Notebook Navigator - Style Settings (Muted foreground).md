## Muted foreground
Muted foreground color.

> [!info] In `plugins/obsidian-style-settings/data.json`
> Only written to `data.json` upon update. If there isn't a `data.json`, it will be created.
> 
> This setting affects the default icon colors and file count colors of Notebook Navigator, as well as the weekday, week, and arrows on Notebook Navigator's calendar.
> 
> Only values set through the color picker are accepted; manually editing the JSON file will have no effect.
> 
> **Default:**
> ```JSON
>   "notebook-navigator-style-settings@@nn-theme-foreground-muted@@light": "#",
>   "notebook-navigator-style-settings@@nn-theme-foreground-muted@@dark": "#"
> ```
> If `⟲` is clicked, the JSON property will be removed from `data.json`.
